# Brag-slim video plan — Muhammad Sufyan Ashraf

**Angle:** An AI engineer who connects practical automation, computer vision, and agentic LLM systems to measurable business outcomes.
**Tone:** Polished cinematic, restrained, confident.
**Format:** Landscape 1920×1080, 30 fps, 20 seconds.
**Visual identity:** Deep navy/near-black, electric cyan and restrained violet accents, crisp Inter typography, fine grid, animated network nodes and abstract product-interface motifs. No fabricated screenshots; UI motifs are illustrative graphics.

## Storyboard

1. **0–4s — Hook / identity**  
   Ai ENGINEER.” / “MUHAMMAD SUFYAN ASHRAF” / “AI/ML ENGINEER · AGENTIC AI · COMPUTER VISION”. A bright network pulse resolves into the title.
2. **4–8s — Real-world automation**  
   “AI AUTOMATION IN POWER STATION.” / “US POWER STATION · PRC COMPLIANCE” / “Computer vision · OCR · LLM / “24h → 90 sec  |  48h → 30 sec ”. Abstract power-grid and inspection visualization.
3. **8–12s — RAG local business assistant**  
   “A SMARTER HOTEL CONCIERGE.” / “Ask naturally about nearby restaurants, spas & hotels.” / “Pinecone hybrid search · BM25 · reranking” / “Grounded answers from real business data.” Animate a hotel guest’s question flowing through FastAPI, dense + keyword retrieval, reranking, and a concise recommendation grounded in retrieved business records.
4. **12–16s — AI agent for sales managers**  
   “ASK IN PLAIN ENGLISH. GET THE DATA.” / “CrewAI · DeepSeek R1 · SQL” / “Question → SQL → validated query → answer, chart or dashboard.” Show a sales manager asking a business question in natural language. The system first searches a vector database of verified client SQL examples and question/answer variations; if there is no suitable match, DeepSeek R1 generates SQL. A separate LLM validates the query, with regeneration allowed for up to three attempts. Once valid, the query runs against the database and the result is returned as a written answer, a chart when requested, or a dashboard created from a natural-language request. Briefly visualize the preparation pipeline: client and generated SQL examples → manually checked SQL → question/answer pairs and paraphrased derivatives → DeepSeek R1 fine-tuning data + vector database. Keep the animation legible: emphasize retrieval, validation (✓), execution, then the requested output. Do not imply every generated query is guaranteed correct; show validation and the three-attempt limit.
5. **16–20s — Close / CTA**  
   “BUILDING WHAT’S NEXT.” / “Agentic AI research · Python · LangGraph · Azure · AWS · FastApi ” / “Explore my work · github.com/sufyanAshraf ”. Clean final lockup.

**Share copy:** “From power-station compliance automation to RAG, fine-tuned LLMs and agentic workflows, I build AI systems designed to solve real operational problems. Explore my work: github.com/sufyanAshraf”
